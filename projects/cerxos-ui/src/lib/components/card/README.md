# Cxs Card

Token-driven card container for Cerxos UI.

## Usage

```html
<cxs-card>
  <h3>Title</h3>
  <p>Content</p>
</cxs-card>
```

## Inputs

- `variant`: `surface` | `muted` | `outline` (default: `surface`)
- `size`: `sm` | `md` | `lg` (default: `md`)
- `elevated`: boolean (default: `true`)
- `ariaLabel`: string
- `ariaLabelledby`: string

## Tokens

- `--cxs-color-surface`
- `--cxs-color-surface-hover`
- `--cxs-color-on-surface`
- `--cxs-color-border`
- `--cxs-shadow-sm`
- `--cxs-radius-md`
