# Cxs Tooltip

Token-driven tooltip component for inline hints.

## Usage

```html
<cxs-tooltip text="View profile">
  <cxs-button size="sm" variant="ghost">Profile</cxs-button>
</cxs-tooltip>
```

## Inputs

- `text`: string (default: empty)
- `position`: `top` | `right` | `bottom` | `left` (default: `top`)
- `disabled`: boolean (default: `false`)

## Tokens

- `--cxs-color-on-primary`
- `--cxs-color-on-surface`
- `--cxs-radius-md`
- `--cxs-shadow-sm`
